# PetScan

PetScan es una aplicación móvil basada en inteligencia artificial que clasifica mascotas a partir de imágenes mediante visión artificial y aprendizaje automático (machine learning). La aplicación reconoce cinco categorías: perros, gatos, aves, roedores y reptiles.

El modelo de clasificación se basa en una red neuronal convolucional (CNN, por sus siglas en inglés) y se ejecuta localmente en el dispositivo mediante TensorFlow Lite, lo que permite obtener predicciones rápidas sin necesidad de conexión a internet.

## Características
- Clasificación de imágenes de mascotas
- Inferencia en el propio dispositivo mediante TensorFlow Lite
- Predicciones rápidas y sin conexión
- Interfaz de usuario móvil moderna
- Compatibilidad con iOS

## Tecnologías utilizadas
- Kotlin
- Compose Multiplatform
- TensorFlow Lite
- Visión artificial
- Aprendizaje automático (Machine Learning)
